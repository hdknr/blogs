## 概要

センサー選定は「何を測るか」だけでは決まらない。**目的・物理量・信号インターフェース**の3軸で整理すると、実装（どのマイコンで受けるか）と調達（どこで買うか）まで一直線につながる。

## 軸1：信号インターフェース7種

実装コストを決めるのはここで、物理量よりも先に効く。

| 種別 | 用途と注意点 |
| --- | --- |
| デジタル通信（I2C / SPI / UART） | 小型センサーの定番。配線が短い前提 |
| アナログ電圧 | ADC で読む。ノイズと基準電圧の管理が要る |
| 専用高速バス | 画像・音声など帯域が要るもの |
| デジタル入力（GPIO / 無電圧接点） | 接点の開閉、パルスカウント |
| 産業用シリアル（RS-485 / Modbus RTU） | 長距離・マルチドロップ。既存設備との接続に強い |
| アナログ電流ループ（4-20mA） | 長距離でノイズに強い産業標準。断線検知ができる |
| 近距離無線（BLE / EnOcean） | 配線不要。EnOcean は電池レスも可能 |

現場に既存設備がある場合、**RS-485 / Modbus RTU と 4-20mA を読めるかどうか**が実現可能性を大きく左右する。

## 軸2：物理量カテゴリ

温湿度（SHT3x・BME280・熱電対）、空気質（CO2・PM2.5・ガス・TVOC）、暑熱・気象（WBGT・風速計）、振動、圧力、電流、ひずみ、測位などに分かれる。物理量ごとに定番の型番があり、まずは定番から入るのが失敗が少ない。

## 軸3：目的別の5分類

建設・設備現場では、測定対象そのものより「何のために測るか」で構成が決まる。安全管理（暑熱・ガス）、設備の状態監視（振動・電流）、環境・品質管理（温湿度・CO2）、進捗・稼働把握、測位といった目的別に、必要な精度とサンプリング周期が変わる。

## 通信規格と調達

センサーからの信号を現場外へ運ぶ部分は、消費電力・距離・データ量のトレードオフで LPWA と BLE を使い分ける。部品ショップは扱う領域が異なるため、産業用（Modbus / 4-20mA 系）と開発ボード系（M5Stack など）で調達先を分けることになる。
