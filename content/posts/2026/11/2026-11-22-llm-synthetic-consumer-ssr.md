## はじめに

新商品のコンセプトを消費者調査にかけると、パネルの手配から集計まで時間もお金もかかります。そこで以前から、「LLM に消費者の役を演じさせてアンケートに答えてもらえば、安く速く済むのでは」と考えられてきました。ただ、LLM に「1〜5 で何点ですか」と直接聞くと、ほとんど「3」しか返ってきません。これでは人間の回答分布とまるで似ないのです。

PyMC Labs と Colgate-Palmolive の研究者は、2025 年 10 月に論文 [LLMs Reproduce Human Purchase Intent via Semantic Similarity Elicitation of Likert Ratings](https://arxiv.org/abs/2510.08338)（arXiv:2510.08338）を公開しました。この論文は、**点数を直接聞くのをやめ、自由記述の感想を埋め込みベクトルの類似度で点数の確率分布に変換する**方法を提案しています。著者らはこれを Semantic Similarity Rating（SSR）と呼んでいます。

[X では「合成消費者が人間の再テスト信頼性の 90% に達した」という紹介](https://x.com/HowToPrompt__/status/2124040349068964215)が大きく拡散しました。本記事では論文本文の数値をもとに、次の点を整理します。

- なぜ LLM に点数を直接聞くとうまくいかないのか
- SSR の仕組みと公開実装の使い方
- 実験結果（GPT-4o の SSR で相関到達率 90%・KS 類似度 0.88）と限界、実務での使いどころ

## 用語の整理

| 用語 | 意味 |
|---|---|
| SSR（Semantic Similarity Rating） | 本記事で扱う手法。LLM の自由記述回答を、尺度の各点を表す参照文との意味的な近さで点数の確率分布に変換する |
| 合成消費者（synthetic consumer） | 実在の回答者の属性（年齢・性別・地域・収入など）を与えて、その人物を演じさせた LLM |
| 購買意向（Purchase Intent, PI） | 「この商品を買いたいか」を 1〜5 のリッカート尺度で答えてもらう指標 |
| リッカート尺度 | 「まったく当てはまらない」〜「とても当てはまる」のような段階（ここでは 5 段階）で答えてもらう評定尺度 |
| 埋め込み（embedding） | 文章の意味を数値ベクトルに変換したもの。意味が近い文ほどベクトルも近くなる |
| コサイン類似度 | 2 つのベクトルの向きの近さ。埋め込み同士で計算すると、文の意味の近さの指標になる |
| 再テスト信頼性（test-retest reliability） | 同じ人間の集団に同じ調査を繰り返したとき、結果がどれだけ一致するか。人間同士で到達できる上限の目安 |
| KS 類似度 | 2 つの回答分布の近さ。1 − KS 距離（コルモゴロフ–スミルノフ距離）で、1 に近いほど分布が似ている |
| 相関到達率 ρ | 合成消費者の結果と実調査の結果の相関を、人間同士の再テストの相関で割った値。100% なら人間の再現性と同等 |

## 何が問題だったのか

論文の問題意識は次の一文に集約されています。

> the problem lies not in the use of LLMs themselves, but in directly requesting Likert-scale outputs.

つまり LLM が消費者を演じられないのではなく、**整数 1 つで答えさせるという聞き方**が悪い、という主張です。直接評定では GPT-4o・Gemini-2.0-flash ともに回答が「3」に集中し、1 や 5 はほとんど出てきませんでした。一方、実際の調査では購買意向の平均が 4.0 前後と高い側に偏っており、分布の形がまったく合いません。

## 比較された 3 つの方式

論文では、同じ合成消費者から購買意向を取り出す方法を 3 通り比べています。

![LLM に実在回答者の属性と製品コンセプト画像を与え、直接評定（DLR）・追従評定（FLR）・意味的類似度評定（SSR）の 3 方式で購買意向を取り出す流れと、各方式の KS 類似度を比較した図](/blogs/images/llm-synthetic-consumer-ssr-methods.png)

### DLR（Direct Likert Rating：直接評定）

LLM に「1, 2, 3, 4, 5 のいずれか 1 つの整数で答えて」と指示する素朴な方法です。ベースラインにあたります。

### FLR（Follow-up Likert Rating：追従評定）

まず合成消費者に購買意向を短い自由記述で書かせます。次に、同じモデルの別インスタンスに「リッカート評定の専門家」という役割を与え、その文章を 1〜5 の整数に変換させます。論文によると、専門家役のシステムプロンプトに「どんな文がどの点数にあたるか」の例を入れないと、分布が狭くなってしまったそうです。

### SSR（Semantic Similarity Rating：意味的類似度評定）

自由記述を書かせるところまでは FLR と同じです。違うのは点数化の部分で、LLM に判定させる代わりに埋め込みを使います。

1. 尺度の各点（1〜5）に対応する**参照文（アンカー）**を用意する
2. 合成消費者の回答と各参照文を埋め込みモデル（論文では OpenAI の `text-embedding-3-small`）でベクトル化する
3. 回答と各参照文のコサイン類似度を計算する
4. 類似度を 1〜5 の**確率分布**に変換する

ポイントは、1 つの回答から「4 である確率 0.4、5 である確率 0.3……」という分布が得られることです。「まあ悪くないけど値段次第かな」のような曖昧な感想を、無理に 1 つの整数へ丸めずに済みます。論文では 6 種類の参照文セットそれぞれで分布を求め、平均したものを使っています。

## 実験の設定

- **データ**: パーソナルケア製品のコンセプトを扱った実際の消費者調査 57 件。各調査の回答者は米国の 150〜400 人で、合計 9,300 人
- **刺激**: 製品コンセプトの画像（説明文を含む）。テキストのみの刺激も試され、多くの実験で性能がやや下がった
- **モデル**: GPT-4o と Gemini-2.0-flash。温度 0.5 と 1.5 を試し、差が小さかったため本文では 0.5 の結果を報告
- **合成消費者への条件付け**: 実調査の回答者 1 人ひとりの人口統計属性（年齢・性別・地域・収入・民族など）を与える

## 結果

論文本文で報告されている主な数値をまとめます。

| 方式 | モデル | 相関到達率 ρ | KS 類似度 |
|---|---|---|---|
| DLR | GPT-4o | 約 80% | 0.26 |
| DLR | Gemini-2.0-flash | 約 80% | 0.39 |
| FLR | GPT-4o | 85% | 0.72 |
| FLR | Gemini-2.0-flash | 90% | 0.59 |
| SSR | GPT-4o | 90% | 0.88 |
| SSR | Gemini-2.0-flash | FLR と同程度（※） | 0.80 |

※ 論文本文では「FLR と同程度」とのみ記載されています。

なお、アブストラクトには「KS 類似度 > 0.85」とありますが、本文の値は GPT-4o が 0.88、Gemini-2.0-flash が 0.80 です。0.85 を上回るのは GPT-4o の場合と読むのが正確です。

読み取れるポイントは 3 つです。

- **直接評定でも「どの商品が相対的に人気か」はそこそこ当たる**。ρ は約 80% あり、問題は主に分布の形にあった
- **SSR は順位の再現と分布の再現を両立した**。GPT-4o では ρ 90%・KS 類似度 0.88 と、両方で最良だった
- **FLR は順位では健闘するが、分布の形では SSR に及ばない**

比較として、実調査データで学習させた機械学習モデル（LightGBM）も試されていますが、ρ は 65% にとどまりました。学習データを一切使わない合成消費者のほうが、商品の順位をよく再現したことになります。

## 属性を与えることの意味

興味深いのは、**回答者の属性を与えないとどうなるか**を調べた実験です。Gemini-2.0-flash で属性なしの合成消費者を作ると、KS 類似度は 0.91 に上がりました。平均購買意向も実データと同じ 4.0±0.1 で、分布の見た目はむしろ良くなっています。しかし ρ は最良の参照文セットでも 50% まで落ちています（属性ありでは 92%）。

つまり、属性なしでは「全体としてそれらしい点数」は出せても、**どの商品が好まれるかの区別がつかなくなる**ということです。属性による条件付けは、分布を整えるためではなく、商品間の差を生み出すために効いています。

属性ごとの傾向の再現については、次のような結果が報告されています。

- 年齢と購買意向の関係（中年層がピークの山型）は GPT-4o がよく再現し、Gemini-2.0-flash は部分的な再現にとどまった
- 収入については、家計の苦しさを示す選択肢を選んだ層では購買意向が低く、最も余裕のある層などでだけ明確に高くなるという傾向を、両モデルが再現した
- 製品カテゴリや価格帯による評価の違いも、人間と合成消費者で一致した
- 一方、性別や居住地域による差は再現の精度が低かった

## 自由記述ならではの副産物

SSR や FLR では自由記述を書かせるので、点数だけでなく「なぜそう思ったか」も手に入ります。論文によると、合成消費者の感想は人間の自由回答より情報量がはるかに多く、良い点を挙げつつ懸念点も具体的に述べる傾向がありました。コンセプトの改善点を探る定性調査の下書きとしても使える可能性があります。

## 限界と注意点

論文自身が挙げている注意点（論文）と、実験設定から筆者が読み取った注意点（筆者）です。

- **参照文は手作りで、この 57 件の調査に合わせて調整されている**。別の製品カテゴリや別の質問にそのまま通用するかは検証されていない（論文）
- **埋め込みモデルの選択に結果が依存しうる**（論文。ただし `text-embedding-3-large` に替えても結果はほぼ変わらなかったと報告されている）
- **LLM の知識が乏しい領域では使えない**。学習データにあまり出てこない新しいカテゴリの商品では、もっともらしいだけの回答になりうる（論文）
- **属性ごとの再現度にばらつきがある**。性別や地域による差は十分に再現できていない（論文）
- **対象データが限定的**。米国の回答者・パーソナルケア製品に限られる（筆者）

筆者の補足として、日本語の調査に応用する場合は参照文を日本語で作り直す必要があり、その出来が結果を大きく左右するはずです。論文の数値をそのまま期待するのではなく、手元の過去調査と突き合わせて検証してから使うのが現実的でしょう。

## SSR を試す

著者らは SSR の実装を [pymc-labs/semantic-similarity-rating](https://github.com/pymc-labs/semantic-similarity-rating) として公開しています。README によると、類似度から確率分布への変換は次の手順です。

1. 5 つの参照文との類似度から、その中の最小値を差し引く
2. 合計が 1 になるよう正規化する
3. 必要に応じて温度でスケーリングする

インストールは GitHub から直接行います。

```bash
pip install git+https://github.com/pymc-labs/semantic-similarity-rating.git
```

README の Quick Start は次のとおりです。コードは README のまま（`polars` の別名 `po` や未使用の `numpy` の import も含む）で、コメントだけ筆者が日本語に置き換えています。

```python
import polars as po
import numpy as np
from semantic_similarity_rating import ResponseRater

# 尺度の各点に対応する参照文のセットを 2 種類用意する
reference_set_1 = [
    "Strongly disagree",
    "Disagree",
    "Neutral",
    "Agree",
    "Strongly agree",
]
reference_set_2 = [
    "Disagree a lot",
    "Kinda disagree",
    "Don't know",
    "Kinda agree",
    "Agree a lot",
]
df = po.DataFrame(
    {
        "id": ["set1"] * 5 + ["set2"] * 5,
        "int_response": [1, 2, 3, 4, 5] * 2,
        "sentence": reference_set_1 + reference_set_2,
    }
)

rater = ResponseRater(df)

# 合成消費者の自由記述回答
llm_responses = ["I totally agree", "Not sure about this", "Completely disagree"]

# 回答ごとの確率分布（PMF）を求める
pmfs = rater.get_response_pmfs(
    reference_set_id="set1",      # 使う参照文セット。"mean" で全セットの平均
    llm_responses=llm_responses,
    temperature=1.0,              # 分布の鋭さを調整する温度
    epsilon=0.0,                  # ゼロ除算防止と平滑化のための小さな値
)

# 調査全体としての回答分布にまとめる
survey_pmf = rater.get_survey_response_pmf(pmfs)
print(survey_pmf)
```

実際の購買意向調査に使う場合は、参照文を「絶対に買わない」〜「必ず買う」に相当する購買意向の文に置き換えます。論文と同様に複数の参照文セットを用意し、`reference_set_id="mean"` で平均をとるのがよいでしょう。合成消費者に回答を書かせる部分（属性とコンセプトを与えるプロンプト）は自前で用意することになります。

## マーケティング実務への示唆

この論文は「市場調査が不要になる」ことを示したものではありません。人間の再現性の 90% という数字は、あくまで**多数のコンセプトを相対比較する場面**での話です。

実務で使い道がありそうなのは、次のような場面です。

- 本調査の前に、多数のコンセプト案を合成消費者でふるいにかけ、有望なものだけを実調査に回す
- ペルソナ（属性）ごとの反応の違いをあたりづけし、どのセグメントを深掘りするかを決める
- 自由記述の感想から、コンセプトの懸念点を事前に洗い出す

MA（マーケティングオートメーション）ツールや CRM に蓄積された顧客属性を、合成消費者の条件付けに使う組み合わせも考えられます。ただしその場合も、最終判断は実際の顧客の声で確かめるのが妥当です。

## まとめ

- LLM に購買意向を整数で直接聞くと「3」に偏り、人間の回答分布を再現できない
- SSR は自由記述の感想を埋め込み化し、尺度の各点の参照文との類似度から確率分布を作ることで、この問題を回避する
- 57 件・9,300 人の実調査と比較した結果、GPT-4o の SSR は相関で人間の再テスト信頼性の 90%、分布で KS 類似度 0.88 を達成した
- 回答者の属性を与えることが、商品間の差を再現するうえで決定的に効いている
- 参照文の汎用性や、知識の乏しい領域での振る舞いには課題が残る
