千寻（@Crypto_QianXun）さんが2026年4月のポストで紹介した「Claude + YouTube Shorts = 自動収益化」という手法が注目を集めている。**カメラなし・編集なし・顔出しなし** でバイラルショート動画を量産するアプローチだ。

この記事では、そのコンセプトをもとに、Claude を使った YouTube Shorts コンテンツ自動生成のフローと実践的なプロンプト例・Python コードを解説する。

## YouTube Shorts アルゴリズムが評価する要素 — 顔出しなしでも収益化できる理由

YouTube Shorts のアルゴリズムは **視聴継続率・エンゲージメント** をコンテンツ品質の代理指標として評価する。次の3点が鍵になる。

- **フック（冒頭3秒）** で視聴者を引き込めるか
- **情報密度** が高く最後まで見られるか
- **感情を動かす** テキスト・ナレーションがあるか

これらは人間が画面に映らなくても Claude が生成したスクリプトで十分に実現できる。AI 音声と AI 生成画像/映像を組み合わせれば、顔出し不要のチャンネルが成立する。

Claude が担うのは最初のスクリプト生成だが、これがコンテンツ全体の品質を左右する最重要ステップだ。

## Claude でバイラル Shorts スクリプトを生成するプロンプトの型

### 1. フック特化型プロンプト

```text
あなたは YouTube Shorts のバイラル専門家です。
トピック：[テーマ]
以下の構成で60秒のスクリプトを書いてください：
- 冒頭3秒：視聴者が思わず止まる衝撃的な問いかけ or 事実
- 本編45秒：テンポよく箇条書きで展開
- ラスト12秒：CTA（コメント誘導 or 保存促進）

制約：
- 一文は短く（15文字以内）
- 数字を多用する（例：「94%の人が知らない」）
- 感情語を入れる（驚き・不安・希望）
```

### 2. ジャンル×バイラル要素の組み合わせ型

バイラルになりやすいジャンルとその鉄板フレーズを Claude にコンテキストとして渡してスクリプトを生成させる：

| ジャンル | 効果的なフック例 |
|---------|----------------|
| 金融・投資 | 「月収を3倍にした人が共通してやっていること」 |
| テクノロジー | 「ChatGPT / Claude を使っている99%が知らない機能」 |
| 健康・ライフハック | 「医師が絶対に教えない〇〇の真実」 |
| キャリア | 「年収1000万の人が絶対にしない習慣5つ」 |

### 3. シリーズ化プロンプト

```text
[ジャンル] に関する YouTube Shorts シリーズを企画してください。
条件：
- 各動画は独立して見られるが、シリーズとして繋がる
- 視聴者が「次も見たい」と思うような構成
- 10本分のタイトルと各動画の要点を箇条書きで

ターゲット：[視聴者像]
差別化ポイント：[競合との違い]
```

### 4. トレンドサーフィン型

```text
今週の [ジャンル] 分野で話題になっているトピックを3つ特定し、
それぞれをバイラル YouTube Shorts のスクリプトに変換してください。
各スクリプトは60秒以内、フック→本編→CTAの構成で。
```

## Claude API と Python で自動化する量産パイプライン

### バッチ生成スクリプト

毎日テーマを変えてスクリプトを自動生成したい場合、Claude API を使えば：

```python
import anthropic

client = anthropic.Anthropic()

topics = ["投資", "節約術", "副業", "筋トレ", "読書法"]

for topic in topics:
    message = client.messages.create(
        model="claude-opus-4-7",
        max_tokens=1024,
        messages=[
            {
                "role": "user",
                "content": f"{topic}についてバイラルYouTube Shortsスクリプトを生成してください（60秒以内）"
            }
        ]
    )
    print(f"[{topic}]\n{message.content[0].text}\n")
```

### ニッチジャンルの選び方

Claude に以下を渡して競合の少ないジャンルを発見する：

```text
YouTube Shorts で収益化しやすく、競合が少ないニッチジャンルを
20個提案してください。各ジャンルに対して：
1. 想定視聴者
2. 収益化方法（広告/アフィリエイト/商品販売）
3. 月10本投稿した場合の現実的な見込み収益
```

## 注意点と倫理的配慮

- **情報の正確性を確認すること**：Claude が生成したコンテンツは必ず事実確認を行うこと
- **著作権に注意すること**：既存コンテンツのリライトではなく、オリジナルコンテンツを作成すること
- **視聴者への価値提供を優先すること**：クリックベイトだけでなく、本質的な情報価値を持たせること
- **YouTube ポリシーを遵守すること**：AI 生成コンテンツであることの開示が求められる場合があること

## まとめ

Claude + YouTube Shorts の組み合わせは、コンテンツ量産の参入障壁を大幅に下げる。顔出しや高額な機材が不要なため、コンテンツクリエイターとして活動したい人にとってもチャンスが大きい。

ポイントをまとめると：

1. **フック最優先**：冒頭3秒で視聴者を捕まえるスクリプトを Claude に生成させる
2. **ニッチ選定**：Claude に競合分析させ、参入しやすいジャンルを見つける
3. **シリーズ化**：1回性ではなく継続視聴を促す構成を意識する
4. **自動化パイプライン**：API を使えば毎日のスクリプト生成を完全自動化できる

仕組みを先に整えておくことで、コンテンツ生産のコストを継続的に下げやすくなる。
