X（旧Twitter）のトレンドに「Claudeのユースケース74選が開発者から絶賛の的」という話題が上がっていた。中身を辿ると、Anthropic公式サイトが公開している [Use Cases ページ](https://claude.com/resources/use-cases) のことで、Claude・Claude Cowork・Claude Code の活用例を74件、プロンプト例・手順・使う機能の説明付きでまとめたものだった。

## 何が話題になっているか

きっかけになったのは、AI活用系の発信者・すぐる氏（[@SuguruKun_ai](https://x.com/SuguruKun_ai/status/2038172507807871210)）による次のポスト（要約）。

> Anthropicが公開している「Claudeのユースケース74選」が手厚すぎて神だった。
> Claude / Claude Cowork / Claude Code のユースケースが、プロンプト付き・手順付き・使う機能の説明付きで全部載っている。

反響の理由は、単に「Claudeで何ができるか」の紹介ではなく「どうやるか」まで各ページに書かれている点にある。

## 74件は11カテゴリに分類されていた（2026年7月時点）

Use Casesページの活用例は、対象読者別に11のカテゴリへ整理されていた。件数の内訳は次のとおり。

- Personal（個人向け）: 15件
- Professional（プロフェッショナル向け）: 15件
- Nonprofits（非営利団体向け）: 12件
- Education（教育向け）: 11件
- Finance / Research / Sales / Legal / Life Sciences / Marketing / HR（各業種向け、残り7カテゴリで計21件）

個人ユーザーから非営利団体、教育機関、金融・法務・人事といった業種別の実務まで幅広くカバーする構成だった。

> **追記（2026-09-01）**: その後 Use Cases ページは再編されており、現在はカテゴリが General / Marketing / Product / Engineering / HR / Finance / Operations / Data / Design / Legal / Sales / Research / Education / Personal の14種類、ページ全体も対象読者別ではなく製品別（Claude.ai / Claude Cowork / Claude in Chrome）の構成に変わっている。「74選」という件数表示もページ上からは無くなった。上記の内訳は2026年7月時点のスナップショットとして読んでほしい。

## 具体的にどんな例が載っているか

話題になったポストで紹介されていた例をいくつか挙げる。

- **コードを書かずにポートフォリオサイトを作る** — `Artifacts` 機能を使い、指示の出し方まで手順化されている
- **散らかった180個のファイルを5つのフォルダに自動整理** — `Claude Cowork` にフォルダを読ませて分類させる手順
- **ブランドアセット（ロゴ・配色・フォント）の一括生成** — `Projects` 機能にブランド情報を保存し、繰り返し使い回す流れ
- **投資メモのドラフトを自動作成** — 財務データの読み方とプロンプト例のセット

いずれも「Claudeで何ができるか」ではなく「どうやるか」まで踏み込んでいるのが特徴で、これが「手厚い」と評価されている理由になっている。

`Claude Cowork` はClaude Codeのエージェント基盤をコーディング以外の知的労働に持ち込んだ機能。2026年1月12日にmacOS版Claude Desktopのリサーチプレビューとして Max プラン向けに公開され、1月16日に Pro プランへ拡大、4月9日に macOS / Windows で正式提供が始まった。ローカルフォルダを直接読み書きしてファイル整理やレポート作成を代行するほか、ブラウザ操作も行う（デスクトップではアプリ内蔵ブラウザがデフォルトで、Claude in Chrome を使っている場合はそちらが使われる）。有料プラン（Pro / Max / Team / Enterprise）で利用できる。

## 所感

公式ドキュメントが「機能一覧」ではなく「レシピ集」として機能している点が興味深い。プロンプトエンジニアリングのハードルは、機能そのものの理解ではなく「その機能を使って具体的に何を指示すればよいか」がわからないことにある場合が多い。Use Casesページはその橋渡しをレシピ集の形でカバーしていた。社内でのAI活用を広げたい場合の教材としても使い勝手が良さそうだ。

まだ触っていない場合は、自分の業種・目的に近いカテゴリから覗いてみるのがおすすめ。
